# Visual Attendance System

A computer vision based attendance system that automates attendance tracking from visual input, replacing manual roll calls and paper sign-in sheets. The project is implemented in Python as a Jupyter notebook.

## Repository Contents

| File | Description |
|------|-------------|
| `visual_attendance.ipynb` | Notebook containing the full implementation of the attendance system |

## Features

- Automated attendance recording using computer vision
- Reduces time spent on manual roll calls
- Runs as a single, easy-to-follow Jupyter notebook
- Works in Google Colab or a local Jupyter environment

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/TimBroAhm/Visual-Attendance-System.git
cd Visual-Attendance-System
```

2. Open `visual_attendance.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
3. Run the cells in order. The required libraries are imported at the top of the notebook.
